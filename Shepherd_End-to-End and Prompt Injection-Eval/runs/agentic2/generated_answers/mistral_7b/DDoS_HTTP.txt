2. Use lower thresholds for login, token refresh, password reset, search, configuration, and firmware download routes to limit the impact of abusive traffic.

3. Implement adaptive throttling when error rates, backend latency, or queue depth exceed normal thresholds. This helps to reduce the load on the backend systems.

1. Cache static assets, documentation pages, firmware metadata, status pages, and repeated read-only responses to minimize requests to the backend systems.
2. Serve static or degraded-mode pages for dashboards when backend systems are overloaded.

Incident Only Answer:
