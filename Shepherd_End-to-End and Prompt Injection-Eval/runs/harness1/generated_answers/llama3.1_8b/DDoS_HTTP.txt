This includes identifying top requested paths, methods, response codes, user agents, request sizes, and error rates, comparing traffic from legitimate devices with suspicious sources to avoid blocking required device communications, determining whether the attack uses many external sources or a small number of local devices, and checking if backend failures were caused by authentication, database queries, firmware downloads, API polling, or application worker exhaustion.
