Exposed management services that are not required for investigation should be disabled, and any necessary remote administration should be restricted to a trusted management workstation. Automation rules, cloud integrations, and device-to-device control paths that could allow the compromised endpoint to influence other devices should be suspended. Logs, configuration snapshots, packet captures, device state, and file hashes should be preserved before major remediation changes.

The next step would be to identify and disconnect or protect backup repositories immediately, preventing the backdoor malware from reaching online backups, snapshots, file shares, and archive systems. Additionally, disable compromised credentials, administrative accounts, service accounts, API tokens, and remote access sessions that may be involved in the attack. Finally, block suspicious command-and-control, file-transfer, remote-administration, and lateral-movement traffic to further contain the attack.
