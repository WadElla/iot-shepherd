The administrator should isolate affected endpoints from the network using switch port shutdown, quarantine VLANs, firewall rules, or endpoint isolation where available. 3. Backup any critical data stored on the infected devices, if possible.
4. Use trusted sources for malware removal tools and follow the instructions provided by the respective vendors to clean and restore the affected devices.
5. Notify other affected administrators or network operators about the ongoing ransomware incident to facilitate coordinated containment efforts.
6. After isolating and cleaning the infected devices, restore them to the network gradually to minimize potential disruptions.
7. Monitor the network for any signs of further infections and ensure that all endpoint security measures are up-to-date and properly configured.
